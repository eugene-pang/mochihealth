# Mood Tracker

This is a simple mood tracker built with Streamlit. The app allows users to log their moods, and it visualizes the mood data throughout the day.

## Features:
- Log moods with optional notes.
- Visualize mood changes throughout the day.
- Data is saved in CSV format.

## How to Run:
1. Clone the repository.
2. Install the dependencies with `pip install -r requirements.txt`.
3. Run the app using `streamlit run app.py`.

## Built With:
- Python
- Streamlit
- Pandas
- Matplotlib
